## 📜 PATRÓN OBLIGATORIO

### Para CUALQUIER UI nueva:
1. Crear KnitController en `KnitControllers/`
2. Usar `Knit.CreateController({ Name = "XXX" })`
3. Implementar `KnitInit()` y `KnitStart()`
4. NO usar LocalScripts sueltos

### Para CUALQUIER lógica de servidor:
1. Crear Service en `Services/`
2. Usar `Knit.CreateService({ Name = "XXX", Client = {} })`
3. Implementar `KnitInit()` y `KnitStart()`

## 🔌 SISTEMAS EXISTENTES

### Sistema de Turrets:
- **Service:** `TurretService.luau`
- **Definiciones:** `TurretDefinitions.luau`
- **Tipos:** MachineGun, Laser, Missile, Tesla
- **Tiers:** T1-T5 (debe comprar en orden secuencial)
- **Compra:** A través de TurretService, NO a través de RequestPurchase

### Sistema de Upgrades (Legacy):
- **Archivo:** `MainServer.lua`
- **RemoteEvent:** `RequestPurchase`
- **IDs:** Upgrade_1, Upgrade_2, etc.
- **Categorías:** Income, Defense, Utility

### Sistema de Economía:
- **Módulo:** `EconomyModule.lua`
- **BaseModule:** Maneja HP, Guardian, muerte
- **RemoteFunction:** `RequestState` para obtener cash y datos
